# Contributing and Documentation Guidelines

This is primarily a personal research repository. Suggestions and corrections are welcome.

## Content principles

- Prefer primary documentation, standards, vendor documentation, and reputable research.
- Distinguish facts, hypotheses, and personal observations.
- Include dates and tool versions when relevant.
- Explain commands and configuration choices; do not paste unexplained command dumps.
- Make labs reproducible where practical.
- State assumptions, limitations, and safety boundaries.
- Credit external sources and respect their licenses.

## Naming conventions

- Use lowercase kebab-case for folders and filenames.
- Use descriptive names, for example `linux-file-permissions-lab`.
- Use `README.md` for folder landing pages.
- Use `-pt-BR.md` for Portuguese companion documents.

## Before publishing

- [ ] No credentials, tokens, keys, or personal data.
- [ ] No employer-confidential information.
- [ ] Testing was performed in an authorized environment.
- [ ] Commands and screenshots were reviewed for sensitive details.
- [ ] Sources and tool versions are documented.
- [ ] Simulated results are clearly identified.
